# THIS SUCKS.™
### Small mouth. BIG business.

**The world's tiniest CEO. The world's biggest pacifier ambitions.**

Meet Babu: a two-year-old with a pacifier obsession, questionable management practices, and an unreasonable amount of corporate ambition.

THIS SUCKS.™ is his company. What started as a baby's attachment to a pacifier has grown into a business empire featuring questionable products, a cardboard-box headquarters, an unknowing employee, and a dog who takes his Chief Security Officer title far too seriously.

Welcome to the business of sucking.

🔗 **Live Website:** https://this-sucks-plum.vercel.app/  
📖 **About & Lore Dossier:** https://this-sucks-plum.vercel.app/about.html

## 🍼 The Business

Every great company starts with a problem.

Ours started with a baby who refused to let go of his pacifier.

Rather than addressing the problem like a responsible adult, Babu did what any ambitious entrepreneur would do: he built an entire company around it.

Now, he runs THIS SUCKS.™ from his bedroom headquarters, with toys serving as his board of directors and absolutely no evidence of a functioning HR department.

His mother? An employee. She just doesn't know it yet.

His dog, Tommy? Chief Security Officer. He guards the inventory, barks at potential thieves, occasionally eats company assets, and has an impressive record of sleeping on the job.

**The mission:** Turn a baby's obsession into a business opportunity.  
**The vision:** Global pacifier domination.  
**The management philosophy:** If it sucks, it sells.

## ✨ Features

This isn't just a landing page. It's a tiny corporate universe with an unreasonable number of things to discover.

### 🧸 The CEO Experience
Meet Babu, the company's pint-sized founder. His eyes follow your cursor, because even at two years old, he's keeping an eye on the competition.

### 🛍️ The Product Catalogue
Explore three distinct pacifier products, each designed to serve the company's very specific business interests.

### 📖 The Origin Story
Discover how a baby's pacifier obsession became a corporate empire through an interactive scroll-driven autobiography and an alternating journey timeline.

### 🎮 Pacifier Chase
Take a break from corporate responsibilities and play a little game. Because even the CEO needs to chase something occasionally.

### 📚 The Interactive Storybook
Explore Babu's origin through an interactive 3D WebGL virtual flipbook experience with realistic page-mesh physics.

### 📈 Live Stonks Candlestick Chart
Monitor THIS SUCKS.™ Corp market cap and inject executive bull pumps directly with real-time candlestick dynamics.

### 🌗 Day & Night Mode
The company respects work-life balance. When night falls, Babu and Tommy go to sleep, and the chase game takes a break too.

Some things are better left undisclosed. There's a hidden musical Easter egg waiting for curious visitors with an interactive vinyl turntable and dancing Babu.

### 💬 The Grievance Desk & Guestbook
Have a complaint? A suggestion? A strongly worded message for management? The guestbook is open with real-time sentiment analysis and playful CEO responses.

### 🤖 Meet the Characters
Interact with the characters and discover the personalities behind the company's questionable organisational structure.

### 🧠 Returning Visitor Memory
The website remembers returning visitors using privacy-friendly client identifiers, triggering contextual CEO greetings upon return.

### ✨ Small Details, Big Personality
From a custom dot cursor and interactive audio soundboard to a live visitor odometer, the experience is filled with little touches designed to make exploring the company fun.

**Department:** Pacifier Acquisition and Executive Decisions

## 🎨 Design Philosophy

THIS SUCKS.™ was built around a simple idea: **a website can be functional without taking itself seriously.**

The experience combines playful storytelling, interactive details, character-driven humour, and a polished neobrutalist visual presentation.

The goal was to make the website feel like a real company's digital presence while allowing the absurdity of its leadership to shine through.

Every interaction is an opportunity for a little personality. Every section has a purpose. And somewhere, a dog is eating the inventory.

## 🛠️ Built With

The project uses a modern web stack combining frontend interactivity, backend resilience, and cloud services.

### Frontend
- **Vite 6** — Modern lightning-fast build tooling and module bundler
- **Vanilla JavaScript (ES Modules)** — Dynamic interactive DOM engine
- **Tailwind CSS 3** — Neobrutalist design system tokens and styling
- **React 19 & React DOM** — OriginKit custom interactive cursor overlay
- **DearFlip Engine & Three.js** — 3D WebGL paper mesh virtual book engine
- **HTML5 Canvas & Web Audio API** — Real-time candlestick stonks chart and audio soundboard
- **canvas-confetti** — Executive celebration confetti bursts

### Backend & API
- **Node.js (>=20)** — JavaScript runtime
- **Express 5** — Backend REST API server with sliding-window rate limiting
- **SQLite (WAL Mode)** — Resilient local fallback persistence for orders, guestbook, and stats
- **Vercel Serverless Functions** — Cloud API endpoints (`/api/orders`, `/api/guestbook`)

### Cloud & Database
- **Google Firebase 13 & Firebase Admin 14** — Cloud Firestore for visitor counter and reviews
- **Firebase Authentication** — Client-side Email/Password authentication

## 🚀 Running Locally

Want to explore the company's operations on your own machine?

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) (bundled with Node.js)
- [Git](https://git-scm.com/)

### 1. Clone the repository

```bash
git clone https://github.com/ayushgujran-stack/hax.baby-BABU.git
cd hax.baby-BABU
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

This launches both processes concurrently:
- **Vite Frontend Dev Server:** [http://localhost:3000](http://localhost:3000)
- **Express API Server:** [http://localhost:3001](http://localhost:3001)

### 4. Run test suites

```bash
npm test
```

Runs all 6 comprehensive test suites covering sentiment classification, guestbook persistence, orders, scroll animation, journey timeline, and stonks chart.

### 5. Build for production

```bash
npm run build
npm run preview
```
